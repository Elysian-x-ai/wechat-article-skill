# 去 AI 味检查清单（中文）

写完**必过**。逐条对照，命中就改。中文长文最容易露机器味的地方就在下面这些模式里。

## 一元命中：见到就改

| 机器味写法 | 改成 |
|---|---|
| 首先…其次…最后… | 直接分段，靠内容顺序表达先后，不写序号词 |
| 总之 / 综上所述 / 由此可见 / 值得一提的是 / 不难发现 / 需要注意的是 | 删掉，或换成一句具体的结论 |
| 不仅…而且… / 既…又… | 拆成两句，或只留更重要的那半句 |
| 在当今这个 <X> 的时代 | 从一个具体场景或数字开头 |
| 极大地 / 显著地 / 有效地 提升了效率 | 给数字或具体动作：「原来要 20 分钟，现在 3 分钟」 |
| 希望对你有帮助 / 如有不当之处欢迎指正 / 让我们一起期待 | 删掉。结尾给读者一个明确动作 |
| 这是一个…的工具，它可以帮助你… | 「我用它 <做了什么>」 |
| 需要注意的是，… | 直接写那件事 |
| 赋能 / 闭环 / 一站式 / 抓手 / 生态 | 说人话，或删 |

## 二元特征：整体扫一遍

1. **段落长度是否高度一致**？真人写东西，段落长短会参差 —— 有的一行，有的七八行。全都 3 行的排版像宣传册。**故意让长短交错。**
2. **小标题是否都是同一句式、同一字数**？全是四字动宾短语（"快速上手""深度解析"）就是模板产物。**至少有一个小标题是不规则的、带具体信息的**（如「导入简历会踩的坑：字段错位」）。
3. **有没有具体到奇怪的细节**？真人记忆里有这类东西：`Ctrl+Shift+T`、某个按钮在右上角、报错信息的确切文字、某个数字不对（`31/64`）。整篇没有一处这种细节，就是没跑过。
4. **有没有承认不确定或不如意**？全是好话 = 广告。至少一处「这个我没跑通」「这里会有限制」。
5. **冒号 + 解释**的结构是不是反复出现？"结论：…""原因：…""建议：…"。连用三次以上就改成正常句子。
6. **形容词密度**。一段里超过 2 个评价性形容词（"非常好用""相当流畅""十分强大"）就砍，换成可验证的描述。
7. **过渡句**。真人写长文不写"接下来让我们看看"「下面我将介绍」—— 直接进下一节。

## 三元：保留原有的个人特征

- 母本里作者自己的口头习惯、括号里的吐槽、自嘲、口语词（"说实话""我原本以为"）**要保留**，不要为了"书面化"抹掉。这些是去 AI 味最有效的成分。
- 不要为了"专业感"把短句合并成长句。
- 不要统一标点风格到全角/半角的完美状态。

## 最后一关

把文章**念出来**（或用 TTS 听一遍）。凡是念着别扭、换气困难、或者一听就像新闻播报的句子，重写。
