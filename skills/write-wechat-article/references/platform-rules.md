# 微信平台硬限制（与具体账号无关）

标注 `[实测]` 的是在 mp.weixin.qq.com 后台实际操作验证过的；其余是平台规则。

## 字段上限 `[实测]`

| 字段 | 上限 | 位置 |
|---|---|---|
| 标题 | **64 字** | 编辑器标题区（计数器形如 `31/64`） |
| 摘要 | **120 字** | `#js_description`，`max-length="120"`；**留空则自动抓正文开头** |
| 作者 | — | 普通 input |
| 菜单一级名 | 4 汉字 / 8 字母 | 仅中英文和数字，**不支持 emoji** |
| 菜单二级名 | 8 汉字 / 16 字母 | 同上 |
| 菜单文字消息 | 600 字 | 菜单动作「发送消息 → 文字」 |

## 封面

- 大图封面 **900×383**（≈2.35:1）。另有从正文图裁剪的选项。
- 封面弹窗**无法由自动化触发**（只响应真人点击），见 `mp-editor-automation.md` §8。

## 正文可用结构 `[实测]`

粘贴 HTML 后编辑器保留并规范化：`h2` / `h3` / `p` / `strong` / `em` / `blockquote` / `ul` / `ol` / `table`。

- 图片会被规范化成 `<section nodeleaf><img class="rich_pages wxw-img" contenteditable="false">`。
- **图片必须走素材库**：`https://mmbiz.qpic.cn/...` 的 CDN 地址，靠 `data-imgfileid` 与素材空间关联。
  **`data:` base64 内嵌不可行** —— 编辑器不会把它转成素材，体积极小尚可粘贴，多图必崩，且发表后图不落地。任何"把图 base64 塞进 HTML"的方案都要替换成"上传素材库再引 CDN 地址"。
- 正文里不要指望内联 CSS 生效：公众号发布时会重写样式。**用结构（标签层级）表达排版，不要用颜色/字号硬写**。

## 链接

- **站外链接**（`http(s)://` 非 mp.weixin.qq.com）：
  - 未认证号：正文里只能作为**纯文本**出现，读者需长按复制到浏览器打开，不可点击。
  - 已认证服务号：可加白名单外链（需在后台配置）。
  - 因此未认证号的写法是：URL 单独成段、完整可复制，并提示"复制到浏览器打开"。
- **站内跳转**：只能在已发表图文之间。
- 不能跳小程序、不能网页授权（未认证订阅号）。
- 外链承载的替代方案：菜单「发送消息 → 文字」把 URL 写进消息文本；关键词自动回复同理。

## 发表前置条件 `[实测]`

未完成以下两项时，草稿**无法发表**，且**原创声明的开关点不动**（点「原创」会连带弹出阻断框）：

1. 主体**实名认证**（未实名时提示「公众号尚未实名」）
2. 设置**头像和名称**（提示「未设置头像和名称，发表内容需要完善公众号头像和名称」）

这两项是账号所有者本人才能完成的，自动化无法代办。**未解决时只保存草稿，不要试图发表。**

## 接口与额度

- 素材管理 / 草稿箱 API **需要认证主体**。个人未认证订阅号拿不到，所以个人号只能走浏览器自动化。
- 已认证主体应优先走官方 API（更稳），浏览器自动化是退路。
- 订阅号每天可群发 **1 次**；服务号每月 4 次。定稿成本因此比一般平台高 —— 发表前把 Phase 6 的校验做完。

## 审核相关

- 标题与正文不得诱导分享/关注、不得用"最"字类绝对化用语、外链指向的落地页要与内容相关。
- 纯工具教程类内容风险低；涉及"账号""代注册""破解"等词容易被拦。
